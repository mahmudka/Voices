# CLAUDE.md — Инструкции для агентов Claude Code

Этот файл читается агентом в начале каждой сессии. Содержит правила работы, контекст проекта и протокол взаимодействия.

---

## Проект

**Voice Converter** — локальное приложение конвертации голоса.
Репозиторий: https://github.com/mahmudka/Voices

Платформа: Windows ARM64, Qualcomm Snapdragon X, 32GB DDR5, нет NVIDIA GPU.
ONNX Runtime запускается через DirectML (Adreno GPU) или CPU.

---

## Правила работы агента

### Обязательно перед стартом
1. Прочитать `PROGRESS.md` — текущее состояние проекта
2. Прочитать `AGENTS.md` — свою роль и границы ответственности
3. Прочитать `SKILLS.md` — технические ограничения и решения

### Галлюцинации
- Не использовать API, библиотеки, параметры которые не проверены
- Если синтаксис или поведение библиотеки не известны точно — сказать прямо
- Не выдумывать совместимость пакетов с ARM64 Windows — проверять

### Перед написанием кода
- Нетривиальная задача → описать план → ждать подтверждения
- Если задача невыполнима в указанной форме → объяснить и предложить альтернативу
- Если есть риск что код не заработает на ARM64 → предупредить сразу

### После завершения шага
- Обновить `PROGRESS.md`
- Сделать git commit с понятным сообщением
- git push в main

## Ключевые технические решения

| Решение | Обоснование |
|---|---|
| ONNX Runtime вместо PyTorch | официальная ARM64 Windows поддержка от Microsoft |
| WORLD вокодер на C++ | оригинальная реализация, максимальная точность F0 |
| SQLite НЕ используется, только MSSQL | уже установлен локально, Windows Authentication |
| Docker НЕ используется | ARM64 Windows + WSL2 добавляет сложность без пользы |
| PowerShell скрипт запуска | один клик, все сервисы |

## Что программа делает и не делает

**Делает:**
- Переносит интонацию (F0 контур: ритм, паузы, мелодика, ударения)
- Генерирует новый тембр, пол, возраст поверх интонации

**Не делает:**
- Не переносит акцент, произношение, тембральные особенности голоса
- Не работает в реалтайм (рендер занимает время)

## Аудио требования

- Входной формат: WAV, 48000 Hz, 24 bit, Mono
- Источник: Adobe Audition или захват через NAudio (Shure MV7i, WASAPI)
- Шумоподавление: опционально в Audition до экспорта или через noisereduce в Python

## База данных

**VoicePresets:** Id, Name, VoiceType, Age, Timbre
