# Voice Converter

Локальное приложение для конвертации голоса с сохранением интонации.
Ты записываешь текст с интонацией — программа генерирует нужный тембр, пол и возраст, сохраняя твой интонационный рисунок.

---

## Что делает приложение

- Принимает WAV файл (Adobe Audition) или захватывает голос с микрофона (Shure MV7i)
- Сохраняет интонацию (F0 контур) из оригинальной записи
- Генерирует новый голос: пол (мужской/женский/детский), возраст (5–80 лет), тембр (низкий/средний/высокий)
- Позволяет рендерить несколько вариантов из одного исходника без повторной загрузки
- Хранит историю конвертаций с возможностью удаления файлов и записей

---

## Важно

Программа переносит **только интонацию** (ритм, паузы, мелодика, ударения).
Акцент, произношение и тембральные особенности голоса не переносятся.

---

## Архитектура

Микросервисная. Каждый компонент отвечает за свою задачу:

| Сервис | Технология | Порт |
|---|---|---|
| UI | React + Vite + shadcn/ui | 5173 |
| Оркестратор | ASP.NET Core MVC (C#) | 5000 |
| ML сервис | Python + FastAPI | 8001 |
| Синтез | C++ + WORLD вокодер | 8002 |
| База данных | MSSQL (локальный) | 1433 |

---

## Поток данных

```
Вход (WAV файл или микрофон)
  → ASP.NET Core (оркестратор, SignalR прогресс)
  → Python FastAPI (librosa анализ + ONNX конвертация тембра)
  → C++ WORLD (F0 перенос + форманты + синтез)
  → Результат WAV → браузер
```

---

## Хранение файлов

```
shared/
  audio/
    input/    ← исходные записи
    output/   ← результаты конвертации
```

Все файлы привязаны к сессии в MSSQL. Удаление через UI удаляет файл с диска и запись из базы одновременно.

---

## Запуск

```powershell
.\scripts\start.ps1
```

Открыть браузер: `http://localhost:5173`

## Фазы разработки

**Phase 1 (текущая):** Запись / загрузка → конвертация голоса → история конвертаций

**Phase 2 (планируется):** Перевод речи — русский → английский / румынский с сохранением голоса
